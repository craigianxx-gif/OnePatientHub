Software Services Agreement

General terms relating to the provision and use of OnePatient Hub software services.

1. Software Service

OnePatient Hub provides a software platform intended to support standardized patient identification, patient information management, healthcare coordination, patient journey tracking, referrals, reporting, and interoperability.

2. Authorized Users

Software access is provided only to authorized users according to the roles and permissions configured within the system.

3. System Availability

The availability and performance of the software may depend on the underlying infrastructure, network connectivity, database services, hosting environment, and other supporting systems.

4. External Integrations

Connections to external healthcare information systems require appropriate technical interfaces, authorization, governance arrangements, security controls, and agreements with the relevant system owners.

5. System Maintenance

Software components may be updated, modified, or maintained to improve functionality, security, reliability, interoperability, and system performance.

6. Prototype Scope

The current OnePatient Hub implementation is a prototype and should not be interpreted as a production service agreement or a guarantee of production-level availability or service performance.

7. Future Production Deployment

Any production deployment should be governed by formal agreements covering service ownership, responsibilities, security, data protection, availability, support, maintenance, interoperability, and applicable regulatory requirements.
